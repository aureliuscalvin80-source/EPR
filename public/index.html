Stock planning

Safety stock = Z × σ(monthly sales) × √((lead time + check interval) ÷ 30.4). Reorder point = daily sales × (lead time + check interval) + safety stock, compared with stock on hand + on order. Order up to = daily sales × (lead time + 2 × check interval) + safety stock, rounded up to the SKU's minimum order and order multiple. Months where stock was zero at both the start and end are left out.

Import products

Excel or CSV. Recognised headers: Kode / SKU, Nama / Name, Satuan / Unit, Qty / Stok, Harga Jual / Sell price, Harga Beli / HPP / Cost, PPN / Tax, Min, MOQ. Rows with the same SKU and ledger are updated; columns missing from the file keep their current values.

Export and backup

The backup holds products, costs, contacts, invoices, receivables, purchase orders, all payments, expenses, payroll and employees. Download one every month and keep it outside this app. (The data folder on the server is the complete copy.)

Example data
